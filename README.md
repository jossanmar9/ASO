## Estructura del repositori

Cada unitat disposa del seu propi directori, on s'organitzen els exercicis, scripts, pràctiques i documentació corresponents. Dins de cada unitat, les pràctiques es guarden en una carpeta per sessió.

Els fitxers `README.md` de cada unitat documenten els continguts i el treball realitzat.
